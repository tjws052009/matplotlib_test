# Pull request body

Copy this skeleton. Keep the titles. Delete the HTML comments before `gh pr create`.

The GitHub title is the `PR name` line and nothing else.

~~~~markdown
## PR name

<!-- one line, for example: Add ability to plot timedeltas -->

## Description

<!-- what changed and why. Include `Closes #8869` or `Fixes #8869`. -->

## Impact

<!-- who is affected, and what behavior or docs change -->

## Decisions

<!-- what was chosen and what was rejected. Write None. when there are none. -->

## AI disclosure

<!-- how AI was used, or: No AI was used. -->

## PR quality check

- [ ] Use an expressive title, e.g. "Fix title font property precedence"
- [ ] New and changed code is [tested](https://matplotlib.org/devdocs/devel/testing.html)
- [ ] Plotting related features are demonstrated in an [example](https://matplotlib.org/devdocs/devel/document.html#write-examples-and-tutorials)
- [ ] New features and API changes have  [release notes](https://matplotlib.org/devdocs/devel/api_changes.html#announce-changes-deprecations-and-new-features)
- [ ] Documentation complies with [general](https://matplotlib.org/devdocs/devel/document.html#write-rest-pages) and [docstring](https://matplotlib.org/devdocs/devel/document.html#write-docstrings) guidelines
~~~~
