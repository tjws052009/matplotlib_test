# Disclose generative AI

The source is the "Use of Generative AI" section of `doc/devel/contribute.rst`. If this skill and that file disagree, follow the file.

The human who submits the change is responsible for it. Question the result, understand it, and verify it. Do not send a change the user cannot explain.

Acceptable: reading the existing code, suggesting an approach, and proofreading the user's own words while staying close to their wording.

Not acceptable:

- An agent or bot opening issues, pull requests, or comments on matplotlib/matplotlib or Discourse on its own.
- A change the user could not have made or checked without the tool.
- Output the user has not understood.
- Using the tool to widen work across many projects at once.

Say how AI was used in the PR's AI disclosure. Low-value AI output is rejected. Do not solve an issue labeled `Good first issue`. Those issues are for a person learning the project.

On this fork, act only when the user asked for the change, and still fill in the AI disclosure.
